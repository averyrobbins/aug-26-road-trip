# August 2026 road trip

A small, self-contained report and interactive purchase map. No build service,
JavaScript package manager, or external map API is required. All data, styles,
scripts, and geographic outlines are local to this repository.

## Public site

[Open the report and trip map](https://averyrobbins.github.io/aug-26-road-trip/).

Repository: `averyrobbins/aug-26-road-trip`. The owner approved the reviewed
draft for public publication on September 7, 2026. See
[PRIVACY_REVIEW.md](PRIVACY_REVIEW.md) for what remains public and the review
checklist for future updates.

## Preview

From this folder:

```bash
python3 -m http.server 8795 --bind 127.0.0.1
```

Open `http://127.0.0.1:8795/`. You can also open `index.html` directly; the page
uses bundled JavaScript data and does not fetch external files or map tiles.

## GitHub Pages

The publishing source is **main → /(root)**, using GitHub's branch deployment
and the `.nojekyll` marker for plain static publishing. No custom Actions
workflow is necessary. Relative asset URLs support the project subpath.

For future approved updates, review and commit this folder only, then push
`main`. Never copy a private repository's Git history. Wait for the Pages
deployment to succeed before treating a new revision as live.

See GitHub's [publishing-source instructions](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Future refreshes are generated by the local `update-road-trip-site` skill.
Refresh does not commit, push, enable Pages, or approve publication.

Geographic outlines: U.S. Census Bureau. Points show approximate purchase
locations, not a GPS trace or verified driven route.
